What is Generative AI and Agentic AI?
Generative AI: It means user ask a prompt "can you build a calculator application"
The generative AI will generate code, text, content and user will copy that code and paste it into any ide then it will run.

Generative AI divided into 2 parts:
LLM(Large Language Model): User write text -> model will generate text(i.e Text based model.)
MultiModel: User write text -> model will generate image, video

Agentic AI: Here use will ask a prompt "can you build a calculator application" 
The Agentic AI will generate the code, text, content within the code base and build the app rectify the bugs while build the application fix those bugs again build the application. So it do all the things on it own based on our prompt. No need to do copy paste the code.

Which organization having both i.e LLM and MultiModel?
Open AI: LLM & MultiModel(Using ChatGPT we can generate text and image aslo.)
Anthropic: Mostly focused only on LLM but not in MultiModel.
